SparkyLinux Gaming Setup

Required packages

Download the required .deb files from their official release pages. Do NOT install these packages manually. The setup program will ask you to select the downloaded .deb files during installation.

  • Compositor & LineXinBar & lxb-retroarch
  • DistriBumpy
  • CEDM
  • ImagOnSole
  • VideOnSole
  • SongOnSole

After installation

The installation terminal will close automatically when the setup is finished.

After the installation is complete, reboot your PC.
